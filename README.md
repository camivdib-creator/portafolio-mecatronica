# Portafolio Web - Mecatrónica & Tecnologías Creativas
### Camila Nazareth Valerio Romero

Portafolio vocacional e interactivo orientado a la postulación a becas universitarias y proyectos de ingeniería mecatrónica.

## 🚀 Características
- **Diseño Responsivo & Moderno:** Desarrollado con Tailwind CSS.
- **Modo Oscuro / Cyber:** Paleta de colores tecnológica y moderna.
- **Secciones incluidas:**
  - Perfil profesional y vocacional
  - Proyecto Escolar y prototipos
  - Fundamentos y visión en Ingeniería Mecatrónica
  - El Arte de la Disciplina & Gimnasia
  - Expediente de evidencias y logros
  - Canales de contacto

## 💻 Visualización local
Simplemente abre el archivo \index.html\ en cualquier navegador web moderno.
